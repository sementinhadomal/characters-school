# Characters School — Site Completo

Versão de produção do site Characters School com suporte a rotas SPA, vídeo de alta qualidade e integração estática.

## 🚀 Páginas incluídas
- `/` — Página principal
- `/obrigado` — Página de agradecimento
- `/aula` — Videoaula Premium
- `/aulas` — Endereço alternativo para a videoaula

## 📁 Estrutura de Arquivos
- `index.html` — Ponto de entrada da aplicação React SPA
- `assets/` — Bundles compilados de CSS, JavaScript e o vídeo da aula (`aula-pt.mp4`)
- `vercel.json` — Configuração para roteamento de SPA na Vercel
- `_redirects` — Regras de redirecionamento SPA para provedores compatíveis (ex: Netlify)
- `robots.txt` / `favicon.svg` — Arquivos públicos de SEO e identidade visual

## 🛠️ Tecnologias
- React / Vite SPA
- Vercel Hosting
- HTML5 / CSS3 / JavaScript
